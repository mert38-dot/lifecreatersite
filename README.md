# ✦ LifeCraft

**Kişisel yaşam mimarın.** 10 soruda seni tanır, sana özel bir yaşam tarzı, günlük rutin ve ilham veren rol modeller tasarlar.

**Your personal life architect.** Gets to know you in 10 questions and designs a personalized lifestyle, daily routine, and inspiring role models — just for you.

---

## 📖 Hakkında / About

**TR —** Herkese aynı "ideal rutin" öneriliyor ama enerjin, önceliklerin ve çalışma tarzın herkesinkiyle aynı değil. LifeCraft, cevaplarına göre 8 farklı yaşam tarzı arketipinden (Zen Üretkenliği, Savaşçı Disiplini, Maceracı Ruh...) sana en uygun olanı seçer ve kişiye özel bir sabah/öğle/akşam rutini çıkarır.

**EN —** Generic "ideal routines" rarely fit everyone — your energy, priorities, and way of working are unique. LifeCraft matches your answers against 8 lifestyle archetypes (Zen Productivity, Warrior Discipline, Adventurous Spirit...) and builds a personalized morning/midday/evening routine around the one that fits you best.

## ✨ Özellikler / Features

- 🧠 10 soruluk, ağırlıklı puanlamayla çalışan kişilik eşleştirme motoru
- 🎭 8 yaşam tarzı arketipi — her biri kendi rutini ve ilham veren rol modelleriyle
- 🌍 Tam TR / EN dil desteği, anında dil değişimi
- 🎬 Akıcı geçiş animasyonları, tamamen responsive tasarım
- ⚡ Framework yok, build adımı yok — saf HTML/CSS/JS

## 🛠️ Teknoloji / Tech Stack

Sade HTML, CSS ve JavaScript. Herhangi bir bağımlılık veya build aracı gerekmiyor.

## 🚀 Yerelde çalıştır / Run locally

```bash
git clone https://github.com/mert38-dot/lifecreatersite.git
cd lifecreatersite
python -m http.server 5500
```

Tarayıcıda aç / open in your browser: `http://localhost:5500`
